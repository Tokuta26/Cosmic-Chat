\# Cosmic Chat 🌌

Cosmic Chat — настольный мессенджер, разработанный на C++ с использованием Qt 6 и PostgreSQL.



Возможности приложения:

\- Регистрация и авторизация пользователей.

\- Общий чат и личные сообщения.

\- Сохранение истории сообщений в PostgreSQL.

\- Светлая и тёмная темы оформления.

\- Административная панель Cosmic Control.

\- Просмотр пользователей и сообщений администратором.

\- Блокировка, разблокировка и отключение пользователей.



\## Настройка PostgreSQL



Для работы Cosmic Chat необходим PostgreSQL.



1\. Установите PostgreSQL.

2\. Создайте базу данных с названием `cosmic\\\\\\\\\\\\\\\_chat`.

3\. Откройте базу `cosmic\\\_chat` в pgAdmin 4 и запустите SQL-скрипт `cosmic\\\_chat\\\_schema\\\_final.sql` через Query Tool. Скрипт создаёт таблицы, связи и ограничения. Выполняйте его только в новой пустой базе данных.

4\. Скопируйте файл `database.example.ini` и назовите копию `database.ini`.

5\. Укажите в `database.ini` свои параметры подключения:

&#x20;  - host — адрес сервера PostgreSQL;

&#x20;  - port — порт (обычно 5432);

&#x20;  - name — название базы данных;

&#x20;  - user — пользователь PostgreSQL;

&#x20;  - password — пароль пользователя PostgreSQL.

6\. Поместите заполненный `database.ini` в папку рядом с исполняемым файлом `Chat.exe`.



Не публикуйте `database.ini`, содержащий настоящий пароль.



\## Настройка администратора Cosmic Control



1\. Запустите Cosmic Chat и зарегистрируйте пользователя.

2\. Откройте базу данных `cosmic\_chat` в pgAdmin 4.

3\. Откройте Query Tool и выполните SQL-команду, заменив `admin\_username` на имя зарегистрированного пользователя:



```sql

UPDATE public.users

SET is\_admin = TRUE

WHERE username = 'admin\_username';

```

4\. Перезапустите Cosmic Chat и войдите под этим пользователем.

5\. Администратору станет доступна панель Cosmic Control.
